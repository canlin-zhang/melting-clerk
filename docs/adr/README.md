# Decision records

One decision per file, one paragraph: what was decided, and the reasoning a
future reader would otherwise have to reconstruct. Only decisions that are hard
to reverse, surprising without context, and the result of a real trade-off get
one.

Numbering has gaps. These records were extracted from a working personal setup,
and the decisions that did not come with the extraction — ones about that setup
rather than about this project — kept their original numbers there rather than
being renumbered here. A missing number is not a missing file.
